# 幸福工厂完全攻略百科 · 正式内容版 V1.0

## GitHub Pages 部署
1. 创建 GitHub Public 仓库。
2. 将本目录内 `index.html`、`README.md`、`.nojekyll` 上传到仓库根目录。
3. 打开 Settings → Pages。
4. Source 选择 Deploy from a branch；Branch 选择 `main`；目录选择 `/(root)`。
5. 保存并等待发布，网址格式为 `https://用户名.github.io/仓库名/`。

无需 Node、构建工具或外部依赖。网页 CSS、脚本和正文均内嵌，支持移动端与桌面端。

## 内容边界
本版覆盖主要玩法系统与攻略路径，含 14 个章节。它不是逐条穷尽所有物品、建筑、配方、地图点位的完整结构化游戏数据库。游戏版本和第三方数据库同步状态可能不同，具体数值请以当前游戏内数据复核。
